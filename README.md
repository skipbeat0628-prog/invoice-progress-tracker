# invoice-progress-tracker

發票進度追蹤網站的可遷移原始碼備份。

## 最新版本

- `invoice-progress-tracker-v20-github.zip`
- 對應目前正式網站版本（2026-08-12）
- 原始碼不包含線上客戶資料、密碼、Token 或其他 Secret

## 主要功能

- Excel 客戶資料匯入、進度追蹤與 JSON 還原
- 自動儲存及手動 JSON 備份
- 客編排序（例如 A05 依 A050 的順序排列，畫面不補零）
- 一次搜尋最多 5 個客編
- 多選客戶與批次處理
- 批次登記／取消登記日期
- 批次指定負責人
- 批次設定整理、Key in、檢查與上傳狀態及經手人
- 清除所有資料前確認

舊版 ZIP 保留作為歷史備份。
